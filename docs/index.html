Your library is the source of truth

The game only ever sees a link. Enabling a mod places that link in the mods folder; disabling removes it. Your downloaded zip is never copied, moved, or deleted.

Play

Disabling removes only the link. Swap whole mod sets between saves without re-downloading a thing.

Symlinks don't work for FS25. The Giants engine won't follow them in the mods folder, so symlinked mods fail to load silently. Hardlinks are the default here for exactly that reason.

Know before you load

Maps advertise what they have. Mods declare what they need. Pick the map you're playing and anything that can't work on it gets flagged before the game silently swallows it.

Required disclosure

Code signing policy

This is the published code signing policy for FS25 Mod Manager, as required by the SignPath Foundation free code signing programme for open source.

Certificate and signing

Free code signing for the Windows binaries of this project is provided by SignPath.io, with a certificate issued by the SignPath Foundation.

Signing happens only inside the project's public GitHub Actions release pipeline, triggered by pushing a version tag. No maintainer holds the signing key, and no binary is signed from a local machine. SignPath verifies that each submitted artifact was produced by that pipeline from this repository before it is signed. See the SignPath documentation for how that verification works.

macOS builds are signed and notarized separately with an Apple Developer ID certificate held by the maintainer. That is unrelated to the SignPath Foundation certificate.

Privacy statement

FS25 Mod Manager does not collect analytics, telemetry, or personal data, and does not transmit any information about you or your files to the maintainer. It makes network requests only in these cases, all of them initiated by something you do in the app:

  • Farming Simulator ModHub (farming-simulator.com) — when you browse or search mods in the Discover view. Responses are cached locally.
  • Giants Software CDN (giants-software.com) — when you download a mod you selected in Discover. This is the same host the ModHub website serves downloads from.
  • GitHub Releases (github.com) — when the app checks whether a newer version of itself exists.

Everything else — your mod library, configuration, tag catalog, and scenario data — is stored locally on your own machine and never leaves it. The app requires no account and has no server component operated by the maintainer.

Optional GitHub backup: if you set up external storage in Settings, the app pushes your scenarios, profiles, tag catalog, and savegames to a private GitHub repository that you own, using your own GitHub login. Mods themselves are not uploaded — only a manifest of which ones you had, so they can be re-downloaded from ModHub on another machine.

Reporting a problem

If you believe a signed binary attributed to this project is malicious, tampered with, or was not built from this repository, please open an issue and, if it concerns the certificate itself, contact the SignPath Foundation.
